# 任务日历小程序

> 一款简约的微信小程序任务管理工具，支持日历视图、任务分类、任务进度统计与完成粒子动效，用于日常日程规划与任务追踪。

## ✨ 项目预览

- 日历月视图：日期圆点标记当日任务，打开页面自动弹窗提示今日未完成任务
- 任务管理：新增 / 编辑 / 删除任务，支持设置时间、分类、备注、提醒
- 任务分组：按「今天 / 明天 / 本周」快速筛选任务
- 数据统计：自动计算今日任务完成率，统计各分类任务数量
- 交互特效：任务标记完成时触发星星粒子庆祝动画
- 个人中心：任务概览、明日任务规划、周度海报生成入口

## 🛠 技术栈

- 框架：微信小程序原生 WXML + WXSS + JavaScript
- 存储：小程序本地缓存 `wx.setStorageSync`
- 动画：JS 实现粒子星星特效


## 🚀 快速运行

1. 克隆仓库

```
git clone https://github.com/0220-luoshuizhifeng/personal-schedule-wechat.git
cd personal-schedule-wechat
```

2. 打开微信开发者工具，导入项目文件夹
3. 修改 `project.config.json` 中的 `appid` 为你自己的小程序 AppID
4. 编译运行，即可预览
